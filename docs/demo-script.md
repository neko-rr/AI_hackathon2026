## 3分で見せる操作フロー

| 順 | 操作 | 見せたいポイント | 完了 |
|----|------|----------------|------|
| 1 | 「お試し：タービンって何？」→ **仕掛けを動かす** | 質問が**流体**になり、3つの**タービン**（難易度・対象・場面）を通る | [ ] |
| 2 | 流体の**色・速さが変わる**のを見る | 各タービンのラベル（例：やさしい / 相手 / 審査）が毎回ランダム | [ ] |
| 3 | **📬 届いたアイデア** を読む | 通過したタービン条件に合わせた**回答**が届く | [ ] |

## 自由質問デモ（IO Intelligence 接続時）

| 順 | 操作 | 見せたいポイント | 完了 |
|----|------|----------------|------|
| 1 | 質問欄に **自由入力**（例：「水力発電と風力発電の違いは？」） | API 接続時は画面上部の「デモ版」バナーが**非表示** | [ ] |
| 2 | **仕掛けを動かす** | 流体→3タービン通過→配達口 | [ ] |
| 3 | **届いたアイデア** の回答を読む | AI が条件（難易度・対象・場面）を反映した回答。`fallback` 時のみデモ注記 | [ ] |

## 審査員が触る想定

- 最初に何をクリック/入力するか: **「お試し：タービンって何？」** → **仕掛けを動かす**（2クリック）
- 失敗しやすい操作: 連打でアニメが重なる → 1回押して約4秒待つ
- その場合の代替: もう一度「仕掛けを動かす」（タービン項目は再ランダム）
- IT素人がつまずきそうな点: 「流体」「タービン」は画面上に日本語で表示。API 未接続時はデモ回答のみ（画面上部に案内バナー）

| 項目 | 内容 |

| Chrome確認 | [ ] 済 |

### IO Intelligence 接続デプロイ手順

1. `.env` に `IO_INTELLIGENCE_API_KEY` を設定（[IO ID → API Keys](https://io.net/docs/guides/intelligence/api-keys-and-secrets)）
2. `./infra/deploy-lambda.ps1` → 表示された `POST URL` を `.env` の `VITE_API_URL` に設定
3. `./infra/deploy-s3.ps1` でフロント再ビルド・S3 同期
4. Chrome で公開 URL を開き、自由質問 → **仕掛けを動かす** → AI 回答を確認

### ローカル E2E（開発時）

```powershell
# ターミナル1
cd src/backend
python local_server.py

# ターミナル2
cd src/frontend
npm run dev
```

`src/frontend/.env.development` の `VITE_API_URL=/api/deliver` が vite proxy 経由で接続します。
