# 全日本AIハッカソン 2026 要約

> 本ファイルは [公式ページ](https://www.aifestival.jp/hackathon) を 2026-05-29 時点で整理したものです。受付状況などは変更される可能性があります。

## 概要

2人チーム制のAIハッカソン。予選6ラウンド（オンライン/オフライン）を経て、各ラウンドから決勝進出チームが選ばれ、2026年11月の決勝戦を目指す。予選は1ラウンド30チーム・3ブロック制で、3時間の「高速頭脳バトル」形式。

| 項目 | 内容 |
|------|------|
| 主催 | AIフェスティバル / THIRDWAVE |
| 形式 | オンライン・オフライン併用 |
| チーム人数 | 2人 |
| 開発時間 | 3時間（予選） |
| 公式URL | https://www.aifestival.jp/hackathon |

## 参加条件（2026年予選）

- **チーム構成**: 2人チーム
- **参加費**: **無料**
- **必須**: メンバー全員が**ドスパラ会員**（登録無料）
- **選考**: 定員超過時は抽選（各ラウンド30チーム）

## ルール・レギュレーション（2026年）

詳細 → [レギュレーション要約](zenkoku-ai-hackathon-2026-regulation-summary.md)（**3rd大阪向け**）

| 項目 | 内容 |
|------|------|
| 作品 | **Google Chrome** で体験できるWeb作品 |
| 提出 | ハッカソン終了後、**Web作品URL**を事務局に提出 |

| テーマ | 開始時に告知、ブロックごとに異なる場合あり |

## 開発への示唆（3rd 大阪）

- **Chromeで動くWeb** → デプロイURLを13:30前に確定
- **3分審査** → ログイン不要・主要操作が3分で体験できる設計
- **プレゼン不要** → スライド作成時間を開発に回す
- **動くこと最優先** → アイデアだけでは評価されない
