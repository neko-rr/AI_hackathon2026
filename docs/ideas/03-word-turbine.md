## 一言ピッチ

**モヤモヤを入力すると、言葉が羽根のように回り、AI が「今日の一歩」に変換して返す。**

## 背景・課題

- タービンは「エネルギー変換装置」——**入力を別の価値（動力）に変える**比喩として使える
- 1stラウンドの「Communication」とは異なるが、**個人の内面→前向きな出力**は審査員に共感されやすい
- テキスト入力1つで完結、ログイン不要

## 解決策

### 体験の流れ

```
1. 「今の気持ちを書いてください」（サンプル文ボタンあり）
2. AI がキーワード3つを抽出
3. 画面中央のタービン周りをキーワードが回転
4. 停止後「変換されたエネルギー」＝短い励まし＋今日やる1こと を表示
```

### 核心機能（1つ）

- **感情テキスト → AI構造化 → 回転ビジュアル → 1アクション出力**

## 差別化ポイント

- タービンを「発電」だけでなく**変換・循環**のメタファーに
- デモインパクト：文字が回って止まる瞬間
- IT素人向けコピー（「モヤモヤを、ちいさな一歩に変えます」）

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React + CSS animation | キーワード orbit |
| バックエンド | Lambda | JSON: keywords + action |
| AI/LLM | Bedrock | 抽出＋励まし文 |
| インフラ | S3 + Lambda | 既存 |

## スコープ

### MVP（必須）

- [ ] テキスト入力＋サンプル
- [ ] Bedrock → keywords[3] + actionLine
- [ ] タービン＋キーワード回転アニメ
- [ ] 結果カード表示

### 余力があれば

- [ ] 回転速度を入力文字数に連動

### 今回はやらない

- 履歴保存・ユーザーアカウント

| アニメ実装時間 | 最初はフェード＋rotate のみ |
