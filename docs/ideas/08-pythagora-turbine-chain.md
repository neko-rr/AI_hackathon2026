## 一言ピッチ

**文章を入れると、ピタゴラスイッチのように仕掛けが次々動き、最後にタービンが回って「電気（答え）」が灯る。**

## 背景・課題

- 審査員（IT素人）にとって **「見て楽しい」＝一発で伝わる**
- タービンは発電所では**エネルギー連鎖の最終段**（蒸気→配管→歯車→**タービン**→電気）
- ピタゴラスイッチも **1つのきっかけが連鎖** — 構造がテーマと一致
- 02〜04の良いところ（回転・変換・AI）を1本にまとめられる

## 解決策

### 体験の流れ（固定4段 — 3時間向け）

```
1. 「今日の出来事」or 長い文章を入力（サンプルボタンあり）
2. 「仕掛けを動かす」を押す
3. 【連鎖アニメ約8秒・自動再生】
   ① 入力のキーワードが書かれた玉が坂を転がる
   ② ドミノが倒れる（倒れる面に AI が選んだ単語）
   ③ 歯車／ベルトが回る
   ④ 蒸気 or 風の演出 → タービン加速 → 電球が点灯
4. 電球の横に AI の出力（3行要約 or 今日の一言）を表示
```

### 核心機能（1つ）

- **ユーザー文章 → AI が連鎖用キーワード＋最終メッセージを生成 → 演出付き連鎖 → タービンで完結**

### AI の役割（Must）

Bedrock が JSON を返す:

```json
{
  "chainLabels": ["キーワード1", "キーワード2", "キーワード3"],
  "outputTitle": "今日のエネルギー",
  "outputLines": ["...", "...", "..."]
}
```

連鎖の**動き自体は固定テンプレ**（物理シミュレーションはしない）。

## 既存案との合成

| 要素 | 取り込み元 |
|------|-----------|
| タービン回転・発電メーター | 02 かぜでうごく発電タービン |
| 長文→短い出力 | 04 蒸気タービン要約 |
| 入力のキーワード可視化 | 03 言葉タービン |
| 仕組みの分かりやすさ | 06 図鑑（連鎖＝仕組み説明になる） |

## 差別化ポイント

- **NHK「ピタゴラスイッチ」系の連鎖** — 日本の審査員に説明不要
- タービンが「ゴール」なのでテーマ直球
- 「AIが文章をエネルギーに分解して連鎖させた」と1文で言える

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React + CSS keyframes / SVG | 固定4段の順次アニメ |
| バックエンド | Lambda | Bedrock JSON |
| AI/LLM | Bedrock Claude | キーワード＋要約 |
| インフラ | S3 + Lambda | 既存 |

## スコープ

### MVP（必須）

- [ ] テキスト入力＋サンプル1本
- [ ] 固定4段連鎖アニメ（クリック1回で完走）
- [ ] タービン回転＋電球点灯
- [ ] Bedrock 出力表示＋フォールバック
- [ ] 画面上部コピー「あなたの言葉が、タービンを回します」

### 余力があれば

- [ ] 連鎖中の SE（ポン・カラン）
- [ ] 02案の風ボタンを最終段の代替に

### 今回はやらない

- Matter.js 等の物理エンジン
- 連鎖パターンの複数種
- ユーザーが仕掛けを組み立てる編集 UI

## 実現性スコア

| A | B | C | D | E | 計 | 判定 |
|---|---|---|---|---|-----|------|
| 2 | 3 | 3 | 2 | 2 | 12 | **有力**（Cが高い） |

※ A=2 の理由: 連鎖アニメに90分程度必要。**固定4段に厳守**すれば 3 に近づく。

## 最大リスクと対策

| リスク | 対策 |
|--------|------|
| アニメ実装が重い | 4段固定・SVG translate/rotate のみ。12:00までに連鎖Must |
| API遅延で連鎖とズレ | 押下直後に API 開始、アニメ2秒目から labels 差し替え |
| 物理っぽく見せられない | ピタゴラは「誇張した因果」でOK — 本物の物理不要 |
