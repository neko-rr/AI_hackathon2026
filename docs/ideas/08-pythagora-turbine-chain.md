## 一言ピッチ

**疑問や「思いつかない」を入れると、ピタゴラの仕掛けが動き、タービンから自分では思いつかなかった答えやアイデアが“配達”される。**

## コンセプト（2モード・1装置）

同じ連鎖アニメ・同じタービン。**入口の意図だけ2つ**。審査員はボタンで選ぶ（IT素人向け）。

| モード | 入力 | 連鎖に載る文字 | 出力（灯る／届く） |
|--------|------|----------------|-------------------|
| **わからない** | 「タービンって何？」など疑問1行 | **筋の通った3段**（材料→回転→電気） | やさしい説明 2〜3文 |
| **思いつかない** | テーマ・困り・**白紙**（ボタンのみ可） | **意外な3段**（ユーザーが繋げない跳躍） | **届いたアイデア** 1〜3枚 |

**装置の約束:** 「自分の頭では到達できない所から、荷物が届く」

- わからない → **説明**が届く（知の配達）
- 思いつかない → **発想**が届く（ひらめきの配達）

### タービン＝「発送口」の比喩

| 通常のタービン | この作品 |
|---------------|---------|
| エネルギーを**電気**に変換 | モヤモヤを**ひらめき**に変換 |
| 発電 | **発想**（発送） |
| 予測可能な出力 | **意外な**出力 |

## 体験の流れ（固定4段 — 3時間向け）

```
1. モード選択：「わからない」／「思いつかない」（大きな2ボタン）
2. 入力欄（思いつかないモードは空でもOK →「何も思いつかない」サンプル）
3. 「仕掛けを動かす」
4. 【連鎖アニメ約8秒】
   ① 玉（入力の一言 or「？」）
   ② ドミノ3枚（AIが選んだラベル — モードで中身が変わる）
   ③ 歯車
   ④ タービン回転 → 電球点灯 → **配達口からカードがスライドイン**
5. 出力表示
```

### 「発送」演出（Must の1要素）

- タービン横に **チューブ／ポスト** のイラスト
- 点灯と同時に **封筒 or カプセル** が出てくる CSS アニメ
- カード見出し: **「届いたアイデア」** or **「届いた答え」**

## 核心機能

**意図に応じた AI 生成 → 意外な（or わかりやすい）連鎖ラベル → 固定演出 → タービンから配達**

## AI の役割（Bedrock JSON）

### モード A: わからない

```json
{
  "mode": "explain",
  "chainLabels": ["水や風", "ぐるぐる回る", "電気になる"],
  "deliveryTitle": "届いた答え",
  "deliveryItems": [
    { "headline": "タービンとは", "body": "水や風の力で回って、電気を作る装置です。" }
  ]
}
```

### モード B: 思いつかない（メイン差別化）

```json
{
  "mode": "ideate",
  "chainLabels": ["傘", "待ち時間", "くるくる"], 
  "deliveryTitle": "届いたアイデア",
  "deliveryItems": [
    { "headline": "待ち時間タービン", "body": "タービンの回転を、列の残り時間の目安に例えるWeb時計。" },
    { "headline": "傘の羽根", "body": "折りたたみ傘の骨をタービン羽根に見立てた説明図ツール。" }
  ]
}
```

**プロンプト方針（ideate）:**

- 入力から **ユーザーが自力で思いつきにくい** 切り口を2〜3案
- 連鎖ラベルは **論理ジャンプ**（ピタゴラ的な「なぜそこ？」）を意図的に
- 専門用語禁止・各案2文以内

## 差別化（ハッカソン向け）

| 観点 | 内容 |
|------|------|
| テーマ | タービン＝**配達・変換の最終装置** |
| AI | 答えるだけでなく **発想を届ける** |
| 審査 | 審査員が「何も思いつかない」押す → **その場で意外な案** → 記憶に残る |
| チャレンジ | 要約Botでも説明Botでもない **配達装置** |
| 会場文脈 | ハッカソン中の「詰まり」をそのまま入力できる |

## デモ用サンプル入力

| モード | サンプル | 期待する「意外さ」 |
|--------|---------|-------------------|
| わからない | 「タービンって何？」 | 定番説明（安心） |
| 思いつかない | 「タービン」だけ | テーマから離れた連想案 |
| 思いつかない | 「何も思いつかない」（空入力） | 完全ランダム寄りの配達 |
| 思いつかない | 「3時間で作れるWeb」 | 実装可能な意外案 |

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React + CSS keyframes / SVG | 連鎖＋配達アニメ |
| バックエンド | Lambda | mode 別プロンプト |
| AI/LLM | Bedrock Claude | explain / ideate 分岐 |
| インフラ | S3 + Lambda | 既存 |

## スコープ

### MVP（必須）

- [x] 2モード切替 UI
- [x] 固定4段連鎖＋タービン＋配達カード
- [x] ideate モード＋フォールバック（審査の主役）
- [x] explain モード（テーマ説明用サンプル1本）
- [x] コピー:「**思いつかないを、届ける。**」
- [ ] Lambda + Bedrock 接続（`VITE_API_URL` 未設定時はデモフォールバック）

### 余力があれば

- [ ] 配達 SE
- [ ] カードをタップで「もう1件届ける」

## 最大リスクと対策

| リスク | 対策 |
|--------|------|
| ideate が平凡 | プロンプトで「入力から連想距離が遠い案」を明示 |
| ideate が意味不明 | 各案に headline + 1文。連鎖は演出、正解はカード |
| 2モードで工数2倍 | 同じ JSON 形・同じ UI。プロンプトだけ2本 |
