## 一言ピッチ

**日記を書くたびにタービンの羽根が1枚光り、AI がその日の「エネルギー色」を決める。**

## 背景・課題

- 01寄木日記の**タービン版** — 可視化の型は流用可能
- ただし「日記×工芸」から「日記×発電」へ — テーマ適合は中程度
- 複数日グリッドは3時間では重い

## 解決策

### 体験の流れ

```
1. 今日の日記入力（デモは1回で完結）
2. AI が mood → 色・回転速度を決定
3. タービンの羽根1枚が点灯＋全体が少し速く回る
4. 「今日のエネルギー：◯◯」一言
```

### 核心機能（1つ）

- **日記 → AI解釈 → タービン状態更新**

## 差別化ポイント
