## 一言ピッチ

**長い文章を入れると「蒸気」がタービンを回し、AI が3行の要約を「電気」として灯す。**

## 背景・課題

- 蒸気タービンは火力・地熱発電の中心 — テーマの**もう一つの顔**
- 「熱エネルギー→回転→電気」の変換链が教材として分かりやすい（[地熱発電の解説](https://denki.click/geothermal-power/the-heart-of-geothermal-power-the-role-of-turbines/)）
- 要約AIは実装実績が多く、3時間で確実に動かせる

## 解決策

### 体験の流れ

```
1. 長文入力欄（サンプル：ニュース記事風テキスト）
2. 「蒸気を送る」ボタン → 蒸気パーティクル＋タービン回転
3. 回転が止まると「発電完了」→ 3行要約が電球アイコン付きで表示
4. 横に一行「蒸気の力で、長い話を短くしました」
```

### 核心機能（1つ）

- **長文 →（蒸気/回転演出）→ 短い要約** ＝ 情報のエネルギー変換

## 差別化ポイント

- 蒸気タービン型を**視覚メタファー**で再現（工学シミュレーション不要）
- 審査員が「要約の質」も体感できる
- デモ用長文を同梱

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React | 蒸気CSS + タービンSVG |
| バックエンド | Lambda | 要約プロンプト |

| インフラ | S3 + Lambda | 既存 |
