## 一言ピッチ

**風の強さを選ぶとタービンが回り、AI が「何ワットの電気になったか」をやさしく教えてくれる体験型デモ。**

## 背景・課題

- タービン＝「風・水・蒸気の力で回る羽根」が審査員（IT素人）にも直感で伝わる
- 発電の仕組み（運動→電気）を3分で見せられる必要がある
- 複雑な設定なしで「AIが解説している」ことが分かる作品が求められる

## 解決策

### 体験の流れ

```
1. トップ：大きな風力タービンのイラスト＋「風の強さを選んでください」
2. ボタン3つ（弱い / ふつう / 強い）またはスライダー1本
3. タービンが回転速度を変え、発電メーター（kWh/W）が上がる
4. AI が2〜3文で「今日の風ならこんなに電気が作れる」を平易な日本語で表示
```

### 核心機能（1つ）

- **入力（風）→ 回転（タービン）→ 出力（電気＋AI解説）** のエネルギー変換を1画面で見せる

## 差別化ポイント

- テーマ「タービン」に**最も直球**
- 専門用語なし（「AIが天気を考えて説明」程度のラベル）
- CSS/SVG アニメのみで回転 — 画像生成不要

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React + Vite | 既存スタック |
| バックエンド | Lambda | Bedrock 呼び出し |
| AI/LLM | Bedrock Claude | 風速→発電量の説明文（JSON出力） |
| インフラ | S3 + Lambda | 既存 deploy |

## スコープ

### MVP（必須）

- [ ] 風3段階ボタン → タービン回転速度連動
- [ ] 発電量メーター（計算式は簡易でOK）
- [ ] Bedrock がやさしい解説文を返す
- [ ] サンプル「強い風で試す」ボタン

### 余力があれば

- [ ] 都市名入力 → AI がその地域の風イメージを語る

### 今回はやらない

- リアルタイム気象API連携
- 3Dモデル

## 3分デモ想定

| 順 | 操作 | 見せたいポイント |
|----|------|----------------|
| 1 | 「強い風で試す」を押す | すぐ体験開始 |
| 2 | タービン加速・メーター上昇 | タービン＝発電の心臓 |
| 3 | AI解説が表示 | AI活用・平易な日本語 |

## 最大リスクと対策

| リスク | 対策 |
|--------|------|
| Bedrock 遅延 | 固定フォールバック文＋「考え中…」表示 |
| 見た目が地味 | 回転アニメ・メーター数字の変化でインパクト |
