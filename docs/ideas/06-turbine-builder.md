## 一言ピッチ

**「水力 / 風力 / 蒸気」の3種類から選び、AI がやさしく仕組みを説明しながらタービンが完成していく。**

## 背景・課題

- タービンには水力・風力・蒸気・ガス等の種類がある（[Weblio](https://www.weblio.jp/content/%E3%82%BF%E3%83%BC%E3%83%93%E3%83%B3)）
- 教育コンテンツはIT素人審査員に**非常に分かりやすい**
- インタラクションは薄くなるリスク

## 解決策

### 体験の流れ

```
1. 3枚カード「水のタービン」「風のタービン」「蒸気のタービン」
2. 1つタップ → パーツが順にハマるアニメ（羽根→軸→発電機）
3. AI が小学生向けの3文説明
4. 「別のタービンを見る」で切替
```

### 核心機能（1つ）

- **種類選択 → 組み立て可視化 → AI解説**

## 差別化ポイント

- テーマの**百科事典**として直球
- 審査員が「学べた」と感じやすい

## 技術選定

| 項目 | 採用 | 選定理由 |
|------|------|---------|
| フロント | React + SVG | パーツ段階表示 |
| バックエンド | Lambda | 種類別説明文（キャッシュ可） |
| AI/LLM | Bedrock | 平易解説（3種固定ならほぼ静的でも可） |
| インフラ | S3 + Lambda | 既存 |

## スコープ

### MVP（必須）

- [ ] 3種カード UI
- [ ] 1種類分の組み立てアニメ＋説明
- [ ] 残り2種は説明のみでも可（時間次第）

### 余力があれば

- [ ] 3種すべてアニメ

### 今回はやらない

- クイズ

## 3分デモ想定

| 順 | 操作 | 見せたいポイント |
|----|------|----------------|
| 1 | 「風のタービン」選択 | テーマ直球 |
| 2 | 組み立てアニメ | タービンの構造 |
| 3 | AI解説 | やさしい日本語 |

## 最大リスクと対策

| リスク | 対策 |
|--------|------|
| AI活用度が低く見える | 説明を毎回Bedrock生成＋「質問する」1機能 |
| 地味 | 組み立て完了時の光る演出 |

## チームメモ

- AI弱い場合は「タービンについて質問」入力を1つ追加
