## 一言ピッチ

**困りごとを入力すると、AI が複数案を羽根に載せ、回転が止まった1案が「採用エネルギー」として光る。**

## 背景・課題

- ハッカソン自身が「アイデアを絞る」プロセス — **メタ**だが審査員には分かりにくい可能性
- 複数案生成＋ルーレット演出は楽しいが実装・説明コストあり

## 解決策

### 体験の流れ

```
1. 「解決したいこと」を1行入力（例：会議が長い）
2. AI が3案を生成し、タービンの3羽根に表示
3. 「回す」→ 減速停止 → 1案ハイライト
4. 選ばれた案の詳細を2文で表示
```

### 核心機能（1つ）

- **問題 → 複数案生成 → タービンルーレットで1案に収束**

## 差別化ポイント

- 「タービン＝選択・収束」のゲーム感
- AI brainstorm の可視化

## 技術選定
