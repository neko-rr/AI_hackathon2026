## 作品レギュレーション

| 項目 | 内容 |
|------|------|
| 作品形式 | **Webブラウザ（Google Chrome）で体験できる作品** |
| 提出物 | ハッカソン終了後、**Web作品のURLを事務局に提出** |
| テーマ | ハッカソン開始時に発表。テーマに沿った作品を制作 |
| 失格 | 著作権違反・法令違反の疑いがある作品 |

### 不要なもの（2026年予選）

- **プレゼン登壇は不要**
- **発表資料・スライドの作成は不要**
- Google Drive / QRコード提出は**公式要項に記載なし**

## 審査方法（予選）

**デモンストレーション審査** — 審査員が**実際にWeb作品を操作**して審査します。

| 項目 | 内容 |
|------|------|
| 審査時間 | **1チーム3分**（質疑応答含む） |
| 方式 | 審査員が作品を直接使用。チームによるプレゼンは不要 |

### 審査基準（4点）

1. **開発テーマに沿った作品であること**
2. **実装度** — 作品が**動くこと**を重視（アイデアのみは評価しない）
3. **チャレンジ精神** — 知的好奇心・探求心・「ハッカー魂」
4. **AI活用度** — AIをどれだけ活用したか

> 事前の作り込みは評価せず、**その場で作り上げたもの**を評価する。

| 項目 | 内容 |
|------|------|

| AI | 各種AIサービス利用可（**自己契約**） |
